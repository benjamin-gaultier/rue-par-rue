# Find and use the Vasserot block atlas

Why: Sheets exist only for some houses; the atlas by blocks (îlots) draws every building of a block and would cover the rest of the island.

Done when: the atlas source, licence and coverage of the Cité are written in DATA_SOURCES.md; if usable, a first block is traced and shown.

Notes:
- The house sheets come from the Archives nationales under the Licence Ouverte 2.0; check whether the block atlas is published the same way before using it. Unclear licence: block the item for the owner.
